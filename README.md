## About

- I train **small language models** end to end: data curation, training, and evals
- I like building things **from scratch**: an AI agent, a distributed training system, a neural-net library, and a database engine
- On **Hugging Face** I ship models, datasets, and ZeroGPU Spaces
- Current interests: SLM benchmarking, mechanistic interpretability, agentic systems(local model -> frontier model), distributed training, and agent skills
