## About

- 🧠 I train **small language models** end to end — data curation, training, and evals
- 🦀 I like building things **from scratch**: a neural-net library and a database engine, both in Rust
- 🤗 On **Hugging Face** I ship models, datasets, and ZeroGPU Spaces
- 🔬 Current interests: SLM benchmarking, mechanistic interpretability, and agent skills
