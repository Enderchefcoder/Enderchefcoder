## About

- I train **small language models** end to end: data curation, training, and evals.
- I build things **from scratch**: an AI agent harness, a distributed training system, a neural-net library, and a database engine.
- On **Hugging Face** I ship models, datasets, and ZeroGPU Spaces.
- Current interests: SLM benchmarking, mechanistic interpretability, agentic systems (turning local models into frontier-level ones), distributed training, and agent skills.

## Background

I used to work at Glint Research. I left over fake benchmarks, fake model sizes, abuse of other people's hard-earned money, and after they took my DistribAI system as their own. That's my own take on it, and you can draw your own conclusions, but I'd suggest unfollowing them on Huggingface and spreading the word.

These days I work across multiple orgs, including Axiomic Labs, FromZero, and Supralabs.

## Featured projects

| Project | What it is | Stack |
| :-- | :-- | :-- |
| **[NAXIUM](https://github.com/naxium-oss)** | A harness that runs proactively to handle your work and projects in the background. The part people usually find more interesting: it pushes small models well above their normal ceiling. Qwen3.5 4B and 9B end up performing around Sonnet 5 Medium level under it. Still my personal project for now, but it will go open source once it's stable. **NAXIUM Safeguard** is already open source. | `Python` |
| **[DistribAI](https://github.com/naxium-oss/DistribAI)** | A from-scratch distributed training framework for LLMs and SLMs across many consumer devices, whether that's in one household or spread across the world. Security and edge cases are handled for you. This is my project; the similar-looking systems at Glint came after it. | `Python` |
| **[MagicMindNet](https://github.com/Enderchefcoder/MagicMindNet)** | A from-scratch recreation of PyTorch, llama.cpp-style `.gguf` inference, and an LM eval harness, all in one library. Usable as a Python package, written in Rust underneath for speed. | `Rust` `Python` |
| **[RSN_DB](https://github.com/Enderchefcoder/RSN_DB)** | My original project: a database and AI memory system built from the ground up, with personality toggles built in. | `Rust` |
